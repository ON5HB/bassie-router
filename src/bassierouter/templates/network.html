Netwerk

Alle poorten, behalve die voor WAN gebruikt is, worden ingezet als switch. Dus alle geselecteerde poorten werken in hetzelfde netwerk.

De Bassie-router ondersteunt alleen IPv4. Misschien bouwen we IPv6 ooit nog in; tot nu toe niet.

{% if not cfg.bootstrapped %}

Initiele setup

De router heeft nog geen WAN-poort. Alle poorten zijn nu LAN en de bridge heeft het DHCP-adres {{ cfg.gui.bind }} uit het bestaande netwerk, zodat je deze GUI kunt bereiken. Kies bij Provider → WAN & VLAN de poort die WAN moet worden en klik daarna op Toepassen nu.

Sluit je PC vóór Toepassen nu aan op een andere poort dan de gekozen WAN-poort. Op de WAN-poort werkt de GUI daarna niet meer.{% if cfg.interfaces.dhcp_enabled %} De router geeft dan zelf adressen uit in het ingestelde LAN ({{ cfg.interfaces.lan_ip }}).{% else %} Met DHCP-server uit blijft de router adres van de bestaande DHCP-server krijgen.{% endif %}

{% endif %}

LAN DHCP en DNS servers

Standaard uit. Zet dit aan zodra de router het LAN zelf van adressen moet voorzien; anders blijft de router DHCP-klant op een bestaand netwerk en krijgen LAN-clients geen adres van deze router.

Administratie scherm (dit dus)

Je kan het Administratie scherm nooit bereiken vanuit Internet. {% if cfg.interfaces.dhcp_enabled %}Na Toepassen nu staat het op {{ cfg.interfaces.lan_ip }}:{{ cfg.gui.port }}.{% else %}Het luistert nu op {{ cfg.gui.bind }}:{{ cfg.gui.port }}.{% endif %} Aanmelden met root en je SSH-wachtwoord; de sessie duurt 30 minuten.

De knoppen verschijnen zodra je iets wijzigt. Opslaan bewaart én voert meteen toe; Negeren zet alles terug naar de laatst toegepaste stand.
